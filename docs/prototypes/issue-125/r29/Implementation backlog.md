1. **+ Visual only on blank rows** — built r11. The button appears only when the narration is empty. Once a row has text, you add visuals by selecting text.
2. **Split / join rows from a selection** — built r11. Join moves only the selected words. A whole-row selection offers both joins. A mid-row selection (touching neither start nor end) gets no option. A visual anchored before the selection stays behind, clipped at the split. If a selection includes a row's start or end, the right-click menu offers Join to previous/next row and Split into new row. Visuals travel with the text. A visual whose anchor word is in the selection goes with the selection and its end is clipped to match. A visual is never split across two rows. Split puts the new row before the original if the selection includes the start, after it if it includes the end; Split is hidden for a whole-row selection. Join is disabled across a section break. A stage direction moves only if its start is in the selection.
3. **Footage: quick search + Footage sidepanel** — built r12. Logged on the Research side from YouTube. Fields: title, transcript, logger, date logged.
   - Quick add: the default is a search box that filters on any field and shows only unused clips. Speed is the priority.
   - The quick-search box has a **Show used** toggle.
   - New **Show Footage** sidepanel, alongside Show Stash and Comments. It lists all project footage with a more detailed search. Click a used clip to scroll to its placement; a clip used several times shows small arrows to step through them (1/3, 2/3, 3/3). A clip remembers its latest manual trim, even after that instance is changed or deleted, and every new placement uses it (other placed instances keep their own trims). Drag a clip into any row. It has its own thumbnail-size slider, like Stash.
