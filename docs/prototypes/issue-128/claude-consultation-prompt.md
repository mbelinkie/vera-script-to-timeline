## Pilot mechanics

1. Narration edit plus affected B-roll endpoint; words and range must remain
   distinct.
2. Three consecutive rows removed; one atomic selection, readable old evidence,
   truthful selected/skipped result.
3. Multi-row passage moved within a section; both locations with real neighbors,
   one linked identity and one count.
4. Transparent Graphic requiring two ordinary rows to merge; truthful current
   two-row evidence versus one clean result, base still visible, no false row
   pairing.
5. Cross-row music change; document-wide M-identity, independent atomic
   selection and a valid audio-only update, including duration-driven/no-out-word
   treatment.

The harness also exposes a missing-local-file state and a partial update
failure. The accepted S05 design says existing Resolve work stays in place but
does not explicitly classify protected/incompatible work or define partial
results. The spec says unprovable attachment is a conflict and the prior
timeline remains authoritative.
