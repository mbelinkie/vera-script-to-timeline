## Executive disposition

**Highest potential value:** 21.1.2 adds effect discovery and instance control, selective `CopyAttributes`, timeline position/move controls, frame export and loudness analysis. 21.2 adds gridded frame thumbnails, cropped/quality-controlled frame export, color state readback and optional AI Extras *inventory*. These could simplify VERA's bounded production finishing or make multi-hour, unattended Test Bench observations cheaper, **if** an authorized separate host later proves the APIs preserve the claimed exact geometry and output. Nothing in this investigation establishes performance uplift or successful VERA execution.

**Important negative finding:** 21.1.2's `TimelineItem.SetLeftOffset` / `SetRightOffset` describe source-offset adjustment, **not** a supported atomic two-neighbor roll operation. 21.2 adds no documented new explicit roll method. No vendor declaration certifies #477/#473's same-native-UID, non-GUI, 327→351 frame move. This remains **NO-GO on the installed 21.1.1.10 SDK**, **candidate only** on uninstalled 21.1.2/21.2. The [#477 feasibility report](issue-477-native-roll-feasibility.md) is the controlling detailed read-only assessment, including the misleading-success community anecdote and invalid-start-frame caveat.

There is **no dependency** on #480/#473 for this static research: the issue's later Producer-approved ordering correction supersedes the older prep brief's suggestion to stop read-only work. Physical testing still requires #479 compatibility **GO**, #480 independently verified old-version fallback, #473 completed native acceptance and new authorized disposable targets. A #479 Intel NO-GO forbids 21.2 installation on that Intel host even though this report is independently useful for a supported future machine.
