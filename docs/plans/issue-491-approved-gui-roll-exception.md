## Code-only interface and safety boundary

`python/vera_timeline_agent/resolve_gui_roll.py` exposes `OneUseGuiRollActuator(journal, executor).attempt(intent, inventory, readiness)`:

1. `GuiRollIntent`: `actuator_class="gui"`, `operation="M4.edited"`, **existing #473 stage operation ID**, authenticated pristine capture SHA-256, disposable project/timeline/window identities, exact original 11 UIDs with left/right, compiled `ROLL_SCRIPT_SHA256`, and an unexpired, UTC-aware deadline. **Not a bearer token**; the existing controller verifies authority.
2. `PristineSdkInventory`: a **trusted, independently SDK-verified** matching selected native project and timeline, pre-edit 327 boundary, playhead at 327, V1 original item pair, **6 tracks, 11 native UIDs, 1407 frames, 24000/1001**, and original left/right durations. This mirrors only the preflight inputs; the authentic source/media/audio/PCM checks remain #473's existing native readback responsibility.
3. `TrustedUiReadiness`: a **read-only, trusted OS/SDK/UI preflight**, verifying Darwin, precise Resolve Studio `21.1.1.10`, Resolve bundle/process/frontmost/window, Accessibility and automation consent **already enabled**, Edit page, timeline focus, V1-only targeting, no modal, named Roll/nudge menu availability, and the expected Resolve keyboard preset/Command-4/`.` mapping. This must be obtained from independently verified observations, **not** applicant-supplied booleans. The reviewed AppleScript **rechecks** frontmost/window/modal and menu availability at execution time. It never grants TCC permissions or clicks coordinates.
4. The caller must already hold `resolve_native_owner.native_owner(...)` **through the entire operation**, and the adapter checks the *current* inherited native-owner descriptor. `ExistingOneUseJournal.consume_before_effect(intent)` is implemented by the **existing #473 owner**, which must verify the authenticated stage and atomically persist the spent state **before** any OS command; if duplicate, stale, unavailable or ambiguous, stop. A second in-process call is also refused, but the durable journal is authoritative across processes.
5. `FixedRollExecutor.execute_once(window)` must be `SystemEventsRollExecutor` (instantiated explicitly by the future integrator) or a fake in unit tests. The production executor additionally refuses **direct invocation** without the current consumed-dispatch context and owner lock; this internal guard creates no separate approval token. Its script SHA-256 is a **review-pinned literal**, checked both before journal consumption and immediately before OS dispatch so a script edit cannot automatically authorize itself. It runs one fixed, reviewed AppleScript via argument-vector `osascript`, without shell interpolation, caller-supplied scripts, coordinates, project selection, native SDK setters, saving or output signing. Its single menu sequence switches to Edit, focuses the timeline, isolates V1, selects `Trim → Select Nearest Edit To → Roll`, and issues exactly 24 `Trim → Nudge → One Frame Right` menu events. **If any event fails or the executor exits/times out, the result is UNKNOWN; no replay.** A return code of zero still produces only `GuiRollAttempt(state="unknown", native_verified=False, receipt_issued=False)`.

There is deliberately **no CLI or default executor**. Unit tests use fake journal, SDK and UI observations and never communicate with Resolve or execute actual `osascript`. This ticket authorizes **code-only** validation, not a Mac operation.
