## B1: parameter-free authenticated inputs and deterministic prediction

Intent is derived exclusively from the verified manifest event in the independently authenticated geometry/package binding. It is not a caller-supplied gain, route policy or module. Narration uses0dB; eligible authored source-audio events use the manifest audio gain exactly0 or-18dB. The actual compiler uses `audioPolicy="mute"` for No and skips source-audio event emission (`compiler-core-v2.ts`457–460); narration is emitted separately at1397. `makeSourceAudioEvent`1131–1142 takes the verified default gain and stream audioHash/sampleRange. Reject unknown, duplicated or unmapped native audible item/source and unapproved gain/channel/range policy. Available observed properties must not contradict manifest intent; hidden controls are not asserted absent.

Prediction uses exact24000/1001 and48000Hz, FRAME=2002, zero lag and fixed unity comparison gain. There is NO delay/alignment search, output-based calibration, least-squares `_gains`, source selection or gain fitting. Use the accepted v2 fixed `[[1.0]]` metric call chain, not older regression. Accumulation is a fixed source/segment/sample order using the same += mathematics as old_mix. Compare a test-only equivalent old_mix supplied in identical ordering; do not edit it or fabricate old runtime controls. Canonical predicted bytes are IEEE754 finite float64 little-endian interleaved L/R, without a container header. No optional caller normalizer/dither/denormal behavior.

Create prediction before the corresponding native output. On comparison, independently revalidate authenticated inputs and recompute all predicted bytes; require exact equality to committed prediction bytes/hash. Independent provenance and recomputation eliminate free prediction parameters even if some earlier render has been seen.
